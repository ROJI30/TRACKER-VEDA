TRACKER VEDA — SIMPLE LOCAL APP

This is a small, single-person prospect tracker. It does not use Supabase, Firebase, a server, a PWA, service workers, external libraries, or cloud accounts.

START
1. Extract the ZIP.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Click “Add prospect” and enter a name. Changes are saved in this browser on this device.

FEATURES
- Dashboard with prospect counts and follow-ups due today or overdue.
- Add, edit, search, filter, and delete prospects.
- Statuses: New, Contacted, Interested, Converted, Not interested.
- Optional follow-up date, company, phone, and notes.
- Light/dark theme.
- Responsive layout for desktop, tablet, and phone.

IMPORTANT DATA NOTE
Records are saved to this browser's local storage. They are not shared or automatically backed up. Do not clear this browser's site data if you want to keep the records. This is a single-person local app; there are no user accounts or team connections.

For GitHub Pages, upload index.html, styles.css, and app.js to the repository root. README.txt is only instructions. No build step is needed.
